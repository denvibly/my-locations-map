# Карта локаций

Откройте `index.html` в браузере или разместите папку `outputs` на GitHub Pages, Netlify или другом статическом хостинге.

## Подключение

1. В Google Sheets выберите **Файл → Опубликовать в интернете** и опубликуйте вкладку `all`.
2. Скопируйте ID таблицы из URL:
   `https://docs.google.com/spreadsheets/d/ЭТОТ_ID/edit`
3. В `index.html` замените `PASTE_YOUR_GOOGLE_MAPS_API_KEY_HERE` на ваш ключ.
4. Замените `PASTE_SHEET_ID_HERE` на ID таблицы.
5. При необходимости поменяйте `gid=0` на `gid` нужного листа.

## Формат Google Sheets

Первая строка должна содержать заголовки. Поддерживаются русские и английские варианты:

| Название | Широта | Долгота | Примечание |
|---|---:|---:|---|
| Кофейня | 55.751244 | 37.618423 | Встреча в 18:00 |

Также распознаются заголовки `name`, `lat`, `lng`, `note`.

Для вашей вкладки `all` сайт использует `Link` как название, `Latitude` и `Longitude` как координаты, а также показывает в карточке `Project #`, `Address`, `Status` и `Active`.

## Безопасность ключа

Ограничьте Google Maps API key по домену сайта в Google Cloud Console и включите только Maps JavaScript API. Не добавляйте ключ в публичный репозиторий без ограничений по HTTP referrer.
